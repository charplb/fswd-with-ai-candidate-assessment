# FSWD with AI — Candidate Assessment

Premium candidate entry assessment for the Charp **FSWD with AI** course.

## Assessment Overview

- Duration: 90 minutes
- Total score: 100 points
- Format: supervised practical assessment
- Stack: Laravel, MySQL, Inertia.js and React JSX
- AI assistants: not allowed during the assessment
- Technical defense: required after submission

## Candidate Portal

The complete assessment portal is contained in `index.html` and includes:

- Candidate information and readiness verification
- Assessment integrity declaration
- Persistent 90-minute timer
- Five practical assessment questions
- Question progress tracking
- Final submission checklist
- Direct handoff to the official Google Form submission workflow
- Seven-minute technical-defense instructions
- Responsive mobile, tablet and desktop layouts

## GitHub Pages

This repository is designed to run directly through GitHub Pages from the `main` branch and repository root.

## Privacy Notice

Assessment progress is stored locally in the candidate's browser. When the candidate finishes, the portal opens the official Google Form where the mandatory project ZIP and supporting evidence are submitted securely.
